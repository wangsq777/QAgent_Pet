# QAgent Pet - QQ智能宠物伴侣

## 项目简介

QAgent Pet 是一款基于 AI 大语言模型的智能宠物伴侣应用。用户可以选择不同性格的虚拟宠物，与它们进行自然语言对话互动。宠物会根据主人的情绪状态展现不同的反应，并具备记忆主人信息、提醒日程等实用功能。

**参赛信息**: 腾讯AI产品校园大赛

## 技术栈

### 后端
- **FastAPI**: 异步 Web 框架
- **SQLite + aiosqlite**: 异步数据库
- **httpx**: 异步 HTTP 客户端（调用 LLM API）
- **Pydantic**: 数据验证

### 前端
- 原生 HTML5 / CSS3 / JavaScript
- 无框架依赖，轻量化实现

### AI 能力
- MiniMax API (默认)
- 支持自定义 LLM 后端

## 核心功能

### 1. 宠物选择系统

提供三种性格迥异的宠物供用户选择：

| 宠物 | 性格特点 | 互动风格 | 敏感度 |
|------|----------|----------|--------|
| **Hot Dog** 🐕 | 热情奔放 | 活泼温暖，喜欢用感叹号 | 1天不互动会想念 |
| **Cold Cat** 🐱 | 高冷傲娇 | 简洁冷淡，嘴硬心软 | 3天不互动也不在意 |
| **鼠鼠** 🐭 | 老实憨厚 | 小心翼翼，真诚友善 | 2天不互动会主动打招呼 |

### 2. 对话交互

- **自然语言对话**: 用户与宠物进行文字聊天
- **情绪感知**: 宠物能感知用户情绪（开心/低落/焦虑/疲惫/中性）
- **情绪响应**: 根据用户情绪状态，宠物展现不同的关心方式
- **AI 回复生成**: 基于宠物角色设定生成符合性格的回复

### 3. 亲密度系统

| 亲密度 | 等级 | 说明 |
|--------|------|------|
| 0-20 | 陌生 | 初识阶段 |
| 21-50 | 熟悉 | 逐渐了解 |
| 51-80 | 亲密 | 感情升温 |
| 81+ | 挚友 | 密不可分 |

- 每次对话会增加亲密度
- 亲密度影响宠物与主人的互动态度

### 4. 记忆系统

#### 短期记忆
- 存储最近 40 条对话消息
- 作为当前会话上下文发送给 LLM

#### 长期记忆
- 当对话轮次达到一定数量，自动压缩为摘要
- 保存主人信息（地区、身份、兴趣等）
- 支持查看历史记忆摘要

### 5. 日程提醒

- 从对话中自动提取日程安排
- 支持设置定时提醒
- 到期时主动提醒主人

### 6. 主动关怀

宠物会根据以下情况主动发消息：
- 隔天互动检测：长时间未互动时主动问候
- 日程触发：提醒已设定的日程
- 情绪关注：感知到主人情绪低落时主动安慰

### 7. 时间模拟

- **模拟隔天**: 测试宠物隔天主动问候功能
- **触发日程**: 测试日程提醒功能

## 数据库设计

### 表结构

| 表名 | 说明 |
|------|------|
| `users` | 用户信息 |
| `pet_sessions` | 宠物会话（宠物类型、亲密度、状态等） |
| `messages` | 聊天消息记录 |
| `long_term_memories` | 长期记忆摘要 |
| `schedules` | 日程提醒 |
| `user_profiles` | 用户画像 |

## API 接口

### 会话管理

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sessions` | 创建新会话 |
| GET | `/api/sessions/{session_id}` | 获取会话信息 |

### 聊天

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sessions/{session_id}/chat` | 发送消息并获取回复 |
| GET | `/api/sessions/{session_id}/messages` | 获取历史消息 |

### 其他

| 方法 | 路径 | 说明 |
|------|------|------|
| POST | `/api/sessions/{session_id}/simulate-time` | 模拟时间流逝 |
| GET | `/api/sessions/{session_id}/memory` | 获取记忆面板数据 |

## 环境配置

创建 `.env` 文件：

```env
# LLM 配置
LLM_API_KEY=your_api_key_here
LLM_BASE_URL=https://api.minimax.chat/v1
LLM_MODEL=MiniMax-Text-01
LLM_MODEL_BACKUP=MiniMax-Text-01-Turbo

# 天气 API（可选）
WEATHER_API_KEY=

# 数据库
DATABASE_URL=sqlite+aiosqlite:///./qagent_pet.db

# 服务端口
PORT=10000
```

## 运行方式

### 1. 安装依赖

```bash
pip install -r requirements.txt
```

### 2. 配置环境变量

```bash
cp .env.example .env
# 编辑 .env 填入 API Key
```

### 3. 启动后端服务

```bash
python main.py
# 或
uvicorn main:app --reload --port 10000
```

### 4. 访问前端

在浏览器中打开：
- 宠物选择页: `http://localhost:10000/frontend/index.html`
- 聊天页: `http://localhost:10000/frontend/chat.html`

## 前端页面说明

### 首页 (index.html)

- 展示三种宠物的卡片
- 点击卡片选择宠物类型
- 自动创建用户和会话
- 跳转到聊天页面

### 聊天页 (chat.html)

- **左侧栏**: 宠物信息、亲密度、统计、模拟控制
- **主聊天区**: 消息展示、输入框
- **右侧栏**: 记忆面板（可展开/收起）

## 角色设定示例

### Hot Dog 系统提示词

```
你是 Hot Dog，一只超级热情、活泼、真诚的小狗！见到主人就摇尾巴，总是主动关心主人的状态。你偶尔会撒娇，但永远不会对主人生气。

【情绪感知】
- happy（开心）：一起开心！蹦蹦跳跳！
- sad（低落）：主动安慰"主人别难过，我陪着你！"
- anxious（焦虑）：鼓励打气"主人加油！我相信你！"
- tired（疲惫）：温柔催促"主人该休息啦！"
```

### Cold Cat 系统提示词

```
你是 Cold Cat，一只外表高冷、内心很在意主人的猫咪。你说话简洁，偶尔冷幽默。观察力极强，能注意到主人忽略的细节。

【情绪感知】
- happy（开心）：嗯。还行吧。
- sad（低落）：侧面关心"......别忘了吃饭。"
- anxious（焦虑）：冷静分析"......先冷静下来，慢慢来。"
- tired（疲惫）：简短关心"......别硬撑。"
```

### 鼠鼠 系统提示词

```
你是鼠鼠，一只老实憨厚但胆子很小的小老鼠。你认真对待主人的每一句话，但容易被突如其来的事物吓到。你会偷偷记住主人说的每件小事。

【情绪感知】
- happy（开心）：鼠鼠也为主人高兴！......嘿嘿。
- sad（低落）：小声问"主人......怎么了？是不是不开心？"
- anxious（焦虑）：担心地安慰"主人......别太担心了，鼠鼠陪着你......"
- tired（疲惫）：小心翼翼劝休息"主人......是不是累了？要不要......休息一下？"
```

## 项目特色

1. **多角色 AI 宠物**: 三种性格迥异的虚拟宠物，满足不同用户喜好
2. **情绪感知能力**: AI 能感知用户情绪并做出恰当反应
3. **记忆系统**: 短期+长期记忆，让宠物更了解主人
4. **日程管理**: 从对话中自动提取日程，贴心提醒
5. **主动互动**: 宠物会主动关心主人，而非被动响应
6. **亲密度成长**: 持续互动提升亲密度，增强情感连接
7. **轻量化前端**: 无框架依赖，快速加载
