# QAgent Pet 开发计划

## 项目概述

QAgent Pet 是一个 QQ 智能宠物伴侣 Agent 产品，基于腾讯 AI 产品校园大赛（QQ 题目）开发。Demo 采用轻量化架构：单文件 HTML/CSS/JS 前端 + FastAPI Python 后端 + SQLite 数据库 + LLM API。

**技术栈：**

- 后端：FastAPI (Python 3.10+)
- 前端：单文件 HTML/CSS/JS
- 数据库：SQLite
- LLM：DeepSeek / 智谱（OpenAI 兼容格式）
- 天气 API：和风天气
- 部署：Render.com

### 第二阶段：核心功能实现

#### 2.1 API-01 创建会话

**后端实现：**

- POST /api/sessions
- 创建用户记录（如不存在）
- 创建宠物会话记录
- 生成宠物欢迎消息（调用 LLM）
- 返回 session_id 和欢迎消息

**前端实现：**

- 宠物选择页点击后调用 API
- 跳转到聊天界面

#### 2.2 API-03 核心对话

**后端实现：**

- POST /api/sessions/{session_id}/chat
- 接收用户消息
- 组装完整上下文（System Prompt + 长期记忆 + 用户画像 + 亲密度 + Skills + 短期记忆）
- 调用 LLM 生成回复
- 处理日程提取、情绪识别、记忆压缩
- 更新亲密度、最后互动时间

**前端实现：**

- 消息发送和接收
- 消息列表展示（用户右对齐、宠物左对齐）
- 加载状态展示

#### 2.3 Prompt 工程

| 宠物 | 核心人设 | 口头禅 |
|------|----------|--------|
| Hot Dog | 超级热情、活泼、真诚、偶尔撒娇 | "汪！主人！" |
| Cold Cat | 外表高冷、内心在意、简洁、傲娇 | "哼。......才不是关心你。" |
| 鼠鼠 | 老实憨厚、胆子小、小心翼翼 | "鼠鼠我啊......" |

**System Prompt 区域划分：**

- 角色定义
- 情绪感知指令
- 交互节奏指令
- 说话风格指令
- 技能指令
- 记忆指令
- 约束指令

#### 2.4 记忆流转机制

| 阶段 | 内容 | 存储方式 |
|------|------|----------|
| 短期记忆（≤20轮） | 完整对话内容 | messages 表 |
| 溢出处理 | LLM 摘要压缩为 ≤200 字 | 实时处理 |
| 长期记忆 | 压缩后的关键信息摘要 | long_term_memories 表 |

**实现逻辑：**

- 每次对话后检查消息数量
- 超过 20 轮则调用 LLM 压缩早期对话
- 上下文组装时取最近 20 轮 + 所有长期记忆

### 第三阶段：增强功能开发

#### 3.1 情绪感知

**实现方式：**嵌入 System Prompt，LLM 自动识别用户情绪

**情绪分类体系：**

| 情绪标签 | 标识 | Hot Dog | Cold Cat | 鼠鼠 |
|----------|------|---------|----------|------|
| 开心 | happy | 一起开心！ | 嗯。 | 鼠鼠也为主人高兴！ |
| 低落 | sad | 主动安慰 | 侧面关心 | 小声问怎么了 |
| 焦虑 | anxious | 鼓励打气 | 冷静分析 | 担心地安慰 |
| 疲惫 | tired | 催促休息 | 别硬撑 | 小心翼翼劝休息 |
| 中性 | neutral | 正常互动 | 正常互动 | 正常互动 |

#### 3.2 亲密度系统

| 事件 | 亲密度变化 | 说明 |
|------|------------|------|
| 用户主动发消息 | +1 | 每次对话基础增长 |
| 用户情绪低落时互动 | +2 | 关键时刻陪伴加分 |
| 宠物主动关怀被用户回复 | +3 | 主动关怀被回应大幅加分 |
| 用户连续3天未互动 | -1/天 | 疏远惩罚（第4天起） |
| 鼠鼠被吓到 | -5 | 惊吓惩罚 |

**亲密度等级：**

| 等级 | 亲密度范围 | 宠物行为变化 |
|------|------------|--------------|
| 陌生 | 0-20 | 基本礼貌互动，不太主动 |
| 熟悉 | 21-50 | 开始主动关心，偶尔撒娇 |
| 亲密 | 51-80 | 主动关心频繁，分享更多日常 |
| 挚友 | 81-100 | 完全信任，深度情感互动 |

#### 3.3 日程记忆

**日程提取流程：**

1. 用户消息发送后，调用 LLM 判断是否包含日程信息
2. 如包含，提取日程内容和时间
3. 存入 schedules 表
4. Demo 中通过"模拟时间推进"按钮触发日程提醒

#### 3.4 时间感知

**实现方式：**每次对话时后端获取当前时间，注入上下文

| 时间段 | 时间范围 | 宠物行为 |
|--------|----------|----------|
| 深夜 | 23:00-6:00 | 催促睡觉 |
| 早晨 | 6:00-9:00 | 问早安 |
| 白天 | 9:00-18:00 | 正常互动 |
| 晚间 | 18:00-23:00 | 关心一天状态 |
| 节日 | 特定日期 | 触发特殊互动 |

#### 3.5 天气查询

**和风天气 API 调用规格：**

- API 地址：https://devapi.qweather.com/v7/weather/now
- 认证方式：Key 参数（免费版）
- 免费额度：1000次/天

#### 3.6 分享日常

**触发条件：**

- 用户打开页面时随机触发（10%概率）
- "模拟隔天"后必定触发

### 第四阶段：主动关怀与状态机

#### 4.1 主动关怀调度

| 宠物 | 触发条件 | 触发后行为 |
|------|----------|------------|
| Hot Dog | 1天未互动 | 主动发消息表达思念 |
| Cold Cat | 3天未互动 | 50% 概率不回复，50% 概率回冷淡消息 |
| 鼠鼠 | 2天未互动 | 小心翼翼打招呼 |
| 鼠鼠（特殊） | 3天未互动 + 用户主动发消息 | 被吓到，躲起来 5 分钟 |

#### 4.2 宠物状态机

| 状态 | 说明 | 进入条件 | 退出条件 |
|------|------|----------|----------|
| normal | 正常状态，正常回复 | 默认状态 | - |
| hiding | 躲藏状态，不回复消息 | 鼠鼠：3天未互动后用户发消息 | 经过 status_until 时间后自动恢复 |
| excited | 兴奋状态，更热情回复 | Hot Dog：用户长时间未互动后回归 | 下一轮对话后自动恢复 |
| selective | 选择性回复 | Cold Cat：3天未互动后用户发消息 | 50% 概率回复 |

#### 4.3 API-05 模拟时间推进

**请求参数：**

- mode: "next_day"（模拟隔天）/ "schedule_trigger"（触发日程提醒）

**响应：**

- proactive_message: 宠物主动消息
- pet_status: 宠物状态
- schedule_reminder: 日程提醒消息（如有）

## 技术要点

### 1. LLM 调用

- 使用 OpenAI 兼容格式
- 支持 DeepSeek / 智谱
- 实现重试机制和超时处理
- 错误时返回降级回复

### 2. 上下文管理

- System Prompt + 长期记忆 + 用户画像 + 亲密度 + Skills + 短期记忆
- Token 预估：~3000（留有余量）

### 3. 数据库事务

- 对话过程中需要多次数据库操作
- 使用事务确保数据一致性

### 4. 前端状态管理

- 使用原生 JavaScript 管理状态
- 消息列表、宠物状态、亲密度等

## 风险与应对

| 风险 | 影响 | 应对措施 |
|------|------|----------|
| LLM API 调用失败 | 对话无法生成 | 返回降级回复："突然不知道说什么了......" |
| 天气 API 不可用 | 天气功能无法使用 | 跳过天气注入，不影响主流程 |
| 数据库操作失败 | 数据无法保存 | 记录日志，返回友好错误提示 |
| Token 超限 | 上下文过长 | 严格控制上下文长度，优先压缩长期记忆 |
