# QAgent Pet 本地演示方案

---

## 项目概述

QAgent Pet 是一个前后端一体的 Python Web 应用：

- 后端：FastAPI + SQLite（通过 `python main.py` 启动，默认监听 `0.0.0.0:10000`）
- 前端：纯静态 HTML/CSS/JS，由 FastAPI 托管在 `/frontend/` 路由下，浏览器直接访问
- 关键依赖：MiniMax LLM API（必须有效的 `LLM_API_KEY`），天气功能使用 Open-Meteo（免费，无需 Key）
- 数据持久化：`qagent_pet.db`（SQLite，首次启动自动创建）

本地演示的完整入口是一个浏览器 URL：`http://localhost:10000/frontend/index.html`

---

## 演示目标

向观众呈现以下三个核心差异化价值：

1. **主动关怀**：宠物不是等问的工具，会主动找主人
2. **记忆延续**：宠物记住对话细节，关系随时间变化
3. **个性化角色**：三只宠物风格截然不同，还支持自定义宠物

## 准备环境

### 系统要求

- Python 3.10 或以上版本
- 有效的 MiniMax API Key（或其他 OpenAI 兼容格式的 LLM API Key）
- 能访问外网（调用 LLM 和 Open-Meteo 天气 API）
- 现代浏览器（Chrome / Edge / Firefox）

### 环境准备步骤

1. 安装依赖（仅首次需要）：

   ```bash
   pip install -r requirements.txt
   ```

2. 配置 `.env` 文件（仅首次需要，之后无需改动）：

   ```bash
   cp .env.example .env
   ```

   打开 `.env`，至少填写以下字段：

   ```env
   LLM_API_KEY=你的MiniMax_API_Key
   LLM_BASE_URL=https://api.minimax.chat/v1
   LLM_MODEL=MiniMax-M2.5
   ```

   其他字段保持默认值即可用于本地演示。

3. 检查 `.env` 是否已正确保存，且 `LLM_API_KEY` 不是默认占位符。

## 启动步骤

在项目根目录执行：

```bash
python main.py
```

看到以下输出表示启动成功：

```text
INFO:     Application startup complete.
INFO:     Uvicorn running on http://0.0.0.0:10000 (Press CTRL+C to quit)
```

然后在浏览器中打开：

```text
http://localhost:10000/frontend/index.html
```

## 推荐演示脚本 / 讲解顺序

建议按以下顺序演示，每步对应一个核心价值点，讲解和操作同步进行。

### 第一幕：宠物选择（1-2 分钟）

- **操作**：打开首页，展示三只宠物卡片（Hot Dog / Cold Cat / 鼠鼠）
- **讲解要点**：
  - 这不是换皮 AI，每只宠物有截然不同的性格和交互节奏
  - Hot Dog 粘人热情，1天不理会就会主动来找你
  - Cold Cat 高冷傲娇，3天不回来也可能不理你
  - 鼠鼠老实胆小，3天不互动后你去找它会被吓一跳
- **操作**：先选择 **Hot Dog** 进入聊天

### 第二幕：基础对话 + 情绪感知（2-3 分钟）

- **操作**：发送几条消息，先发一条普通消息，再发一条低落的消息（例如"最近压力好大，感觉很焦虑"）
- **讲解要点**：
  - 宠物回复风格符合 Hot Dog 人设（热情、用感叹号、主动安慰）
  - 注意亲密度圆环变化（左侧边栏），情绪低落时亲密度增长更快
  - 宠物能感知情绪并调整回复策略，不是机械问答
- **可选补充**：切换到 Cold Cat 发同样的话，对比截然不同的回应风格

### 第三幕：日程记忆演示（2-3 分钟）

- **操作**：发送"明天我有考试，有点紧张"
- **讲解要点**：宠物会识别日程信息并记录
- **操作**：点击侧边栏的 **"触发日程"** 按钮
- **讲解要点**：
  - 宠物主动发来考试提醒，风格符合其人设
  - 这模拟了真实场景里宠物到时间主动来找你的效果
  - 不是简单的定时提醒，是 AI 从对话中自然提取日程并融入人设

### 第四幕：主动关怀演示（1-2 分钟）

- **操作**：点击侧边栏的 **"模拟隔天"** 按钮
- **讲解要点**：
  - Hot Dog 立刻主动发来思念消息（"汪！主人你去哪了！"）
  - 这体现了产品核心理念：宠物是有主动性的，不是等你问的工具
- **可选**：返回首页换成鼠鼠，模拟隔3天，展示"被吓到"的特殊行为

### 第五幕：记忆面板（1-2 分钟）

- **操作**：点击右上角 **"记忆面板"** 按钮
- **讲解要点**：
  - 展示亲密度等级（陌生 / 熟悉 / 亲密 / 挚友）
  - 用户画像：宠物从对话中自动提取地区、身份、兴趣等信息
  - 长期记忆摘要：超过短期窗口的对话被 LLM 压缩保留
  - 关系是随时间积累的，不是每次都从零开始

### 第六幕：自定义宠物（可选加分项，2-3 分钟）

- **操作**：返回首页，点击 **"创建我的宠物"** 按钮
- **讲解要点**：
  - 输入宠物名字、类型、性格标签、口头禅、特殊习惯
  - AI 会根据这些参数生成专属 System Prompt
  - 展示创建后的宠物出现在宠物列表，可以正常对话

## 重点功能亮点（讲解时可强调）

| 功能 | 亮点描述 |
|------|----------|
| 主动关怀 | 三只宠物触发阈值不同，行为各异，不是简单定时推送 |
| 情绪感知 | 识别 5 种情绪标签，回复策略随情绪变化 |
| 双通道记忆 | 短期对话（近10条）+ 向量语义检索（历史相关信息）同时进入上下文 |
| 长期记忆压缩 | 对话超出窗口后 LLM 自动摘要，关系不会"失忆" |
| 用户画像 | 8个字段自动从对话提取，可手动编辑修正 |
| 亲密度成长 | 互动次数 + 情绪状态共同影响，有量化展示 |
| 自定义宠物 | AI 生成角色 Prompt，创建专属伴侣 |
| 轻量无依赖 | 纯静态前端 + SQLite，本地一键启动，无需额外服务 |

## 可能的故障兜底

| 问题现象 | 可能原因 | 处理方式 |
|----------|----------|----------|
| 启动时报 `UnicodeDecodeError` | `.env` 文件编码问题 | 用 VS Code 确认 `.env` 保存为 UTF-8（不带 BOM） |
| 启动时报 `ModuleNotFoundError` | 依赖未安装 | 重新运行 `pip install -r requirements.txt` |
| 启动时端口被占用（10000） | 其他程序占用 | 在 `.env` 中改 `PORT=10001`，重启后访问对应端口 |
| 浏览器打开白屏 / 页面无内容 | 前端 JS 报错 | 按 F12 查看 Console，通常是 API 请求失败，见下条 |
| 发送消息后无回复 / 报错 | LLM API Key 无效或余额不足 | 检查 `.env` 中 `LLM_API_KEY`，去 MiniMax 控制台确认 Key 有效且有余额 |
| 403 Forbidden 报错 | 浏览器缓存了旧 session | 按 Ctrl+Shift+Delete 清除浏览器缓存，或按 Ctrl+F5 强制刷新 |
| 天气功能无响应 | Open-Meteo 网络超时 | 告知观众天气功能依赖外网，跳过演示，影响不大 |
| 亲密度不变化 | 正常情况（每轮 +1，变化较小） | 讲解时说明"连续对话后亲密度会逐渐提升" |
| 模拟隔天无反应 | session 未正确创建 | 刷新页面，重新选择宠物进入聊天再操作 |

## 演示前检查清单

在正式演示前，建议提前 15 分钟完成以下检查：

- [ ] `.env` 已配置，`LLM_API_KEY` 有效
- [ ] `python main.py` 能正常启动，无报错
- [ ] 浏览器能打开 `http://localhost:10000/frontend/index.html`
- [ ] 选择 Hot Dog 进入聊天，发一条测试消息，宠物有回复
- [ ] "模拟隔天"按钮点击后有主动消息（验证 LLM 调用正常）
- [ ] "触发日程"按钮点击后有响应（先说一句含日程的话再点）
- [ ] 记忆面板可以打开
- [ ] 浏览器窗口大小合适（建议 1280x800 以上），不要开发者工具界面
- [ ] 演示机联网正常（LLM API 和天气 API 都需要外网）
- [ ] 关闭无关标签页，避免演示时误触
- [ ] （可选）清空 `qagent_pet.db` 从头演示干净的初次见面体验：删除 `qagent_pet.db` 后重启服务即可

## 附：快速重置演示环境

如需每次演示从头开始（展示"初次见面"效果）：

```bash
# 停止服务（Ctrl+C）后执行
del qagent_pet.db   # Windows
# 或
rm qagent_pet.db    # macOS/Linux

# 重新启动
python main.py
```

数据库会在启动时自动重建，所有宠物记忆和亲密度清零。
