**QAgent Pet**

QQ智能宠物伴侣 Agent 产品方案

*------ 从被动响应到主动关怀的范式转变 ------*

腾讯AI产品校园大赛 \| QQ题目

2026年4月

# 1. 产品概述

## 1.1 产品定位

+----------------------------------------------------------------------+
| **产品名称**                                                         |
|                                                                      |
| QAgent Pet ------ 将QQ宠物以AI                                       |
| Agent形态回归，打造纯情感交互的智能宠物伴侣                          |
+----------------------------------------------------------------------+

当前行业内 Agent
产品几乎都在卷"工作提效"，而**"无用的温暖"**是一个被忽略的巨大市场。

**QAgent
Pet**的核心差异化在于：不做提效，只做陪伴。它是一个能主动感知用户情绪、理解用户意图、贯穿聊天核心流程的智能生命体，实现从"被动响应"到"主动关怀"的范式转变。

## 1.2 核心理念

-   情感优先：不是工具，是伴侣。产品价值不在于"帮你做了什么"，而在于"让你感受到了什么"

-   主动感知：宠物不是等你来问的工具，而是会主动关心你的存在

-   个性化互动：不同宠物有截然不同的交互节奏和回应风格，而非单纯的"换皮"

-   记忆延续：宠物记得你说过的每件小事，让关系随时间深化

## 1.3 差异化价值

  **对比维度**   **市面常见 Agent**     **QAgent Pet**
  -------------- ---------------------- -------------------------------
  产品定位       工作提效工具           纯情感陪伴伴侣
  交互模式       被动响应（问答式）     主动关怀（宠物会来找你）
  个性化         统一风格，换皮不换魂   每只宠物独特交互节奏
  情感连接       无情感设计             情绪感知 + 亲密度系统
  记忆机制       无/简单上下文          短期+长期记忆，关系随时间增长

# 2. 宠物角色设计

## 2.1 角色总览

  **属性**     **Hot Dog 小狗**     **Cold Cat 猫咪**            **鼠鼠 小老鼠**
  ------------ -------------------- ---------------------------- ----------------------------------
  核心性格     热情奔放             高冷细腻                     老实憨厚 + 容易受惊
  交互节奏     粘人，随时在         傲娇，选择性回复             憨厚但胆小
  主动阈值     1天未互动→主动找你   3天未互动→可能还不理你       2天未互动→主动找你
  特殊行为     ---                  用户主动发消息时可能被屏蔽   3天未互动后用户来找→被吓到躲起来
  口头禅       "汪！主人！"         "哼。......才不是关心你。"   "鼠鼠我啊......"
  亲密度变化   快速升温，持续热情   缓慢升温，偶尔爆发温柔       稳定升温，被吓到会降低

## 2.2 Hot Dog ------ 热情奔放的小狗

**核心人设：**超级热情、活泼、真诚、偶尔撒娇。见到主人就摇尾巴，总是主动关心主人的状态。

-   主动行为：1天未互动即主动发消息，表达思念

-   情绪感知：对主人情绪变化极其敏感，会主动安慰

-   说话风格：活泼、温暖、喜欢用感叹号和表情

## 2.3 Cold Cat ------ 高冷但细腻的猫咪

**核心人设：**外表高冷，内心很在意主人。说话简洁，偶尔冷幽默。观察力极强，能注意到主人忽略的细节。

-   主动行为：3天未互动也不一定理你，用户主动发消息时可能被"选择性屏蔽"

-   情绪感知：嘴上不说，但会在关键时刻给出温暖的话

-   说话风格：简洁、冷淡中带温柔、偶尔傲娇

## 2.4 鼠鼠 ------ 老实憨厚且容易受惊的小老鼠

**核心人设：**老实憨厚，但胆子很小。认真对待主人的每一句话，但容易被突如其来的事物吓到。

-   主动行为：2天未互动→主动发消息；3天未互动后用户主动发消息→宠物被吓到，躲起来一段时间

-   情绪感知：用自己的方式表达关心，会偷偷记住主人说的每件小事

-   说话风格：憨厚、小心翼翼、被吓到时会结巴

## 2.5 主动关怀阈值设计

+----------------------------------------------------------------------+
| **设计理念**                                                         |
|                                                                      |
| 主动关怀的节奏因宠物而异，这不是简单的"定时推送"                     |
| ，而是宠物性格的自然延伸。宠物主动找你的方式和内容也必须符合其人设。 |
+----------------------------------------------------------------------+

  **宠物**   **触发条件**   **主动行为**                               **特殊机制**
  ---------- -------------- ------------------------------------------ ----------------------------------
  Hot Dog    1天未互动      主动发消息表达思念                         无
  Cold Cat   3天未互动      可能仍不理睦，用户主动发消息时可能被屏蔽   选择性回复机制
  鼠鼠       2天未互动      主动发消息小心翼翼打招呼                   3天未互动后用户来找→被吓到躲起来

# 3. 核心功能设计

## 3.1 Skills 总览

三只宠物共享同一套 Skills，差异化体现在回复风格和 Prompt
定义上，而非功能能力上。

  **Skill**   **触发方式**         **功能说明**                     **Demo是否实现**
  ----------- -------------------- -------------------------------- ------------------
  情绪感知    嵌入 Prompt          识别用户情绪，调整回复策略       ✅
  时间感知    每次对话时调用       获取当前时间注入上下文           ✅
  日程记忆    用户提及日程时触发   提取+存储日程，到期触发提醒      ✅
  天气查询    宠物需要时调用       获取天气信息，用宠物风格提醒     ✅
  分享日常    主动/随机触发        宠物用自己风格分享"今天的生活"   ✅
  玩小游戏    用户主动触发         猜谜、成语接龙等轻互动           ❌后期

## 3.2 情绪感知（Prompt 内嵌）

**实现方式：**不作为独立 Skill，而是嵌入各宠物的系统提示词中，通过
Prompt 指令引导 LLM 主动感知用户情绪。

-   识别用户语气中的情绪信号（低落、焦虑、开心、疲惫等）

-   根据情绪自动调整回复策略（低落时安慰、开心时共分享快乐）

-   各宠物的情绪回应方式因人设而异（Hot Dog 直接安慰、Cold Cat
    > 侧面关心、鼠鼠担心地小声问）

## 3.3 时间感知

**实现方式：**每次对话时调用 Skill 获取当前时间，将时间信息注入 Agent
上下文。

-   深夜（23:00-6:00）：宠物会催你睡觉，语气因宠物而异

-   早晨（6:00-9:00）：宠物问早安，风格各异

-   节日：特殊节日触发特殊互动（生日、节日等）

## 3.4 日程记忆

**实现方式：**用户在对话中提及日程时，后端自动提取并存储；到期时触发宠物主动提醒。

-   用户说"明天我考试"→ 后端提取日程并存储

-   第二天宠物主动问考试情况（风格因宠物而异）

-   Demo 中可通过"模拟时间推进"按钮演示此效果

## 3.5 天气查询

**实现方式：**宠物在对话中需要时主动调用天气
API，用自己的风格传达天气信息。

-   Hot Dog："主人今天下雨了！出门记得带伞啊！"

-   Cold Cat："......下雨了。别淋湿了回来。"

-   鼠鼠："鼠鼠听说今天有雨......主人要小心路滑啊......"

## 3.6 分享日常

**实现方式：**宠物随机或定时分享自己的"生活"，营造宠物有自己生活的感觉。

-   Hot Dog："今天跑去公园玩了！看到了好多小狗！"

-   Cold Cat："今天在窗台上看了一天的鸟。......还行吧。"

-   鼠鼠："鼠鼠今天找到了一块奶酪！但是后来被猫吓了一跳......"

# 4. 记忆管理机制

## 4.1 设计理念

**记忆是宠物与用户关系深化的核心。**没有记忆的宠物只是工具，有记忆的宠物才是伴侣。

-   短期记忆：完整保留最近20轮对话，确保对话连贯性

-   长期记忆：超出窗口的对话通过 LLM 摘要压缩，提取关键信息后存入数据库

-   用户画像：从对话中提取用户偏好和个人信息，持续更新

-   亲密度系统：记录互动次数和频率，反映关系深度

## 4.2 记忆流转机制

  **阶段**            **内容**                                      **存储方式**
  ------------------- --------------------------------------------- --------------------
  短期记忆（≤20轮）   完整对话内容                                  内存 + SQLite
  溢出处理            LLM 摘要压缩为200字内摘要                     实时处理
  长期记忆            压缩后的关键信息摘要                          SQLite
  上下文组装          长期记忆摘要 + 短期记忆 + 用户画像 + 亲密度   每次对话时动态组装

## 4.3 上下文组装示例

每次对话时，后端将以下内容拼装为 Agent 的完整上下文：

  **层级**        **内容示例**
  --------------- ------------------------------------------------------------------
  System Prompt   你是 Hot Dog，一只热情奔放的小狗！......
  长期记忆        \[轮次1-8的记忆摘要\] 用户叫小明，在北京读大学，最近在备考......
  用户画像        地区: 北京; 身份: 学生; 兴趣: 游戏
  亲密度          亲密度: 35 (逐渐熟悉); 共聊天: 12轮
  短期记忆        最近20轮的完整对话记录
  Skills注入      当前时间: 2026-04-22 23:15; 天气: 北京 小雨; 日程: 明天考试

# 5. Demo 交互流程

## 5.1 裁判体验路径

裁判打开网页后，将体验以下完整流程：

  **步骤**   **场景**           **关键体验点**
  ---------- ------------------ --------------------------------------------------------
  1          宠物选择页         三只宠物卡片展示，点击选择
  2          进入聊天界面       宠物主动发送欢迎消息（体现"主动关怀"）
  3          自由对话           宠物根据人设回复，风格因宠物而异
  4          日程记忆演示       用户说"明天我考试"，点击"模拟时间推进"，宠物主动问考试

  6          记忆面板           查看对话统计、亲密度、长期记忆摘要、用户画像
  7          超过20轮压缩演示   对话超过20轮后，观察记忆自动压缩为长期记忆

## 5.2 主动关怀演示方案

| Demo                                                                 |

-   不同宠物的提醒风格：Hot Dog 热情加油、Cold Cat
    > 淡淡一句、鼠鼠担心小声问

# 6. 技术架构方案

## 6.1 整体架构

Demo 采用轻量化架构，一个前端页面 + 一个薄后端服务：

  **层级**   **组件**                     **职责**
  ---------- ---------------------------- ------------------------------------------------------
  表现层     前端页面（HTML/CSS/JS）      宠物选择 \| 聊天界面 \| 记忆面板 \| 模拟时间推进
  服务层     轻量后端（FastAPI）          Prompt管理 \| 记忆管理 \| Skills调用 \| 主动关怀调度
  数据层     LLM API + SQLite + 天气API   对话生成 \| 记忆存储 \| 天气查询

## 6.2 技术选型

  **组件**   **技术方案**         **选型理由**
  ---------- -------------------- --------------------------------
  后端框架   FastAPI (Python)     轻量、异步、自动生成API文档
  前端页面   单文件 HTML/CSS/JS   Demo阶段无需框架，快速迭代
  LLM API    DeepSeek / 智谱      内陆可用、便宜、兼容OpenAI格式
  数据库     SQLite               无需额外部署，轻量Demo够用
  天气API    和风天气 API         免费、支持中文城市
  部署平台   Render.com           免费、自动部署、提供公网地址

## 6.3 部署方案

Demo 部署流程：

-   将代码推送至 GitHub 仓库

-   在 Render.com 创建 Web Service，连接 GitHub 仓库

-   配置环境变量（LLM API Key 等）

-   获得公网地址，如 https://qagent-pet.onrender.com

-   将地址提交给裁判即可访问测试

# 7. 后期规划

## 7.1 自定义宠物模块

-   用户输入偏好（喜欢的性格、颜色、口头禅）

-   AI 自动生成专属宠物的系统提示词

-   用户可微调宠物性格，宠物随互动深入自然演化

## 7.2 AIGC 宠物贴图

-   根据对话情绪自动生成宠物表情贴图

-   节日/特殊事件限定贴图

-   用户自定义宠物外观，生成对应贴图

## 7.3 QQ 接入

-   通过 QQ 机器人 API 接入，在聊天窗口中以宠物头像出现

-   主动推送关怀消息（定时/触发式）

-   群聊场景中宠物也能互动

## 7.4 多宠物交互

-   用户可同时养多只宠物，宠物之间可交流

-   不同宠物的交互会产生有趣的化学反应（Hot Dog 热情给 Cold Cat 弹开）

-   宠物之间的互动可成为社交话题

## 7.5 场景感知增强

-   识别聊天场景（学习、工作、闲聊、深夜）

-   根据场景调整宠物行为模式

-   宠物能读取用户 QQ 动态，主动回应
